hugging-Loader

llama.cpp 用の GGUF モデルを、Hugging Face Hub から検索・絞り込み・並列ダウンロード。

ダウンロード macOS / Windows / Linux 対応・無料

Features

できること

🔍

タスク・パラメータ数・量子化で絞り込み

text-generation などのタスク、7B/13Bなどのパラメータ数、Q4_K_M や Q8_0 といった量子化タイプでモデル一覧を絞り込めます。

↕️

一覧のソート

名称・ファイルサイズ・量子化タイプ・パラメータ数・ダウンロード済みかどうかのいずれでも並べ替え可能です。

⚡

並列分割ダウンロード

HTTP Range で1ファイルを複数チャンクに分割し同時ダウンロード。単一接続より速く取得できます。

⏸️

中断からの再開

ダウンロードをキャンセル・中断しても、続きから再開できます。最初からやり直しになりません。

🗂️

ダウンロード済みの管理

保存先フォルダ内の既存ファイルを自動検知して表示。不要になったファイルはアプリから直接削除できます。

⚙️

保存先フォルダを自由に設定

ダウンロード先フォルダは設定画面から自由に変更可能。llama.cppのmodelsフォルダなどを指定できます。
