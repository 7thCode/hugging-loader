hugging-Loader

llama.cpp 用の GGUF モデルを Hugging Face Hub から検索・ダウンロード

最新版: v1.0.0

macOS Apple Silicon (arm64) .dmg をダウンロード
Windows 64bit (x64) .exe をダウンロード
Linux AppImage / 64bit (x64) .AppImage をダウンロード

Debian/Ubuntu系をお使いの場合は .deb パッケージ も利用できます。
いずれも未署名のビルドです。macOSは初回起動時にFinderでアプリを右クリック→「開く」、Windowsは「詳細情報」→「実行」でSmartScreen警告を通過してください。
過去のリリース一覧は Releases から確認できます。

主な機能

  • タスク・パラメータ数・量子化タイプ（Q4_K_M, Q5_K_M, Q8_0 など）で絞り込み検索
  • 一覧を名称・サイズ・量子化タイプ・パラメータ数でソート
  • 並列分割ダウンロード（HTTP Range）と、中断からの再開に対応
  • ダウンロード先フォルダ内の既存ファイルを検知し、削除も可能
  • 保存先フォルダは設定から変更可能
